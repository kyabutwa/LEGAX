# LegaX Authorization Contract

Authorization evaluates:

Participant + Participation + Context + Role + Capability + Credential + Target + Target Current State + Requested Action + Policy + Temporal/Security Constraints.

Decisions include ALLOW, DENY, REQUIRES_REVIEW, REQUIRES_VERIFICATION, REQUIRES_AUTHENTICATION, EXPIRED and INVALID_CONTEXT.

Authentication proves account/session access. Authorization decides whether a specific operation is allowed.
